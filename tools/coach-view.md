The Coach View is a Java application that allows coaches or spectators to select a team,
view their desktop or webcam video feeds, and follow the team's progress during a contest.

It works with any [Contest API](https://ccs-specs.icpc.io/2026-01/contest_api) server,
typically the CDS since most other sources do not support video.

Looking for a web-based alternative? [Team View](team-view) runs in any browser
and is a direct replacement for the Coach View when run in kiosk mode.
